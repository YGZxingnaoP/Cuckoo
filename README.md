供 10 人以下私密使用的轻量级局域网通信工具，完全脱离公网服务器依赖，基于 Radmin VPN 虚拟局域网构建。

## 运行环境

### 系统要求
- **操作系统**：Windows 10 / 11 x64
- **网络环境**：所有参与者需安装 **Radmin VPN** 并连接至同一虚拟网络，获得可达的虚拟 IP（如 `10.x.x.x`）。
- **防火墙设置**：需放行 `runtime\python.exe` 的 TCP/UDP 入站与出站规则。
- **音频设备**：麦克风与扬声器/耳机（语音通话必需，建议佩戴耳机以避免回声）。

### Python 环境
项目内置了嵌入式 Python 环境（位于 `runtime/` 目录），**无需在系统中安装 Python**。
核心依赖库包括：
- `PySide6`：跨平台 UI 框架
- `opencv-python`：投屏画面的缩放与 JPEG 编码
- `mss`：底层高性能屏幕抓取
- `pyaudio`：音频采集与播放
- `numpy`：音频管道向量化计算
- `soundcard`：WASAPI Loopback 系统声音采集

## 核心功能与实现方法

### 1. 投屏共享 (Screen Share)
- **功能**：房主实时采集屏幕画面并广播给所有房客，支持动态调节分辨率（720p/1080p/原画质）与帧率（15/30/60/120 FPS）。
- **实现方法**：
  - 使用 `mss` 进行底层屏幕抓取，`OpenCV` 进行图像缩放与 JPEG 压缩。
  - 接收端采用独立解码线程，内置**智能丢帧机制**（仅解码最新帧），防止网络波动导致画面延迟累积。

### 2. 语音通话 (Voice Chat)
- **功能**：全双工多人语音，支持 50%~300% 音量增幅调节，支持共享电脑系统声音（WASAPI Loopback）。
- **实现方法**：
  - **独立 TCP 通道**：语音使用独立端口，彻底解决与文件/投屏的队头阻塞问题。
  - **专业级音频管道 (Audio Pipeline)**：
    - **发送端 (Tx)**：动态包络噪声门，平滑压制键盘/风扇等环境底噪。
    - **接收端 (Rx)**：抖动缓冲区 (Jitter Buffer) 消除网络电音 + AGC 自动增益 + Tanh 软限幅（极限增幅不破音）。
  - **MCU 混音**：房主端收集所有音源，按 32ms 时间片进行 PCM 叠加混音，排除自身回声后分发。
  - **热插拔支持**：音频线程内部实时监听设备版本，切换麦克风/扬声器瞬间生效，无需重启程序。

### 3. 文件与文件夹传输 (File Transfer)
- **功能**：支持任意类型文件和文件夹传输，完美保留目录结构。支持**断点续传**，传输中断后可一键恢复。
- **实现方法**：
  - **Host 零落地**：房主仅做字节流透明转发，不占用磁盘 IO，不增加延迟。
  - **JSON 状态机断点续传**：接收方在本地维护 JSON 状态文件，记录每个文件的绝对路径、指纹 (Size+Mtime) 和已接收字节数。断线重连后，接收方发送状态 JSON，发送方（即使已重启）收到后**动态重建发送上下文**，从断点处精准续传。
  - **自适应限速**：发送端实时监控发送队列深度，队列积压时自动休眠，防止内存溢出。

### 4. 文字聊天 (Text Chat)
- **功能**：多人实时聊天，显示发送者昵称与时间戳。
- **实现方法**：房主收到文本消息后，通过高优先级信令队列广播给所有客户端，确保文本消息优先送达。

### 5. 网络与连接管理
- **功能**：断线自动回退、在线状态探测、Radmin 辅助工具。
- **实现方法**：
  - 若房主断开连接，房客端会捕获异常并**自动返回启动界面**，无需手动重启软件。
  - 启动界面集成 Radmin VPN 注册表与快捷方式扫描，提供一键启动/安装功能。

## 使用指南

### 1. 启动程序
双击 `run.bat` 或在命令行中执行：
```bash
.\runtime\python.exe main.py
```

### 2. 角色选择
程序启动后弹出对话框：
- **房主（Host）**：输入昵称，点击确认创建房间。
-  **房客（Guest）**：输入昵称 + 房主的 Radmin VPN IP，点击加入房间。
 
### 3. 功能操作\n连接成功后，主窗口左侧为在线列表，右侧为四个功能 Tab：
| Tab | 操作说明 |\n|-----|---------|
| **投屏** | 房主点击「开始投屏」，可动态调节分辨率和帧率。房客端自动渲染画面。 |
| **语音** | 点击「开启麦克风」发言。拖动滑块调节对方声音增幅。房主可开启「共享电脑声音」。 |
| **文件** | 选择目标用户 → 选择文件或文件夹。若传输中断，可在下方「中断任务列表」点击**继续传输**或**清除**。 |
**文字** | 输入文字发送，所有人实时可见。 |

### 4. 断点续传操作\n若文件/文件夹传输过程中发生断网或程序关闭：
1. 重新连接房间后，进入**文件 Tab**。
2. 在下方的「中断的传输任务」列表中，选中未完成的文件。
3. 点击绿色的**「继续传输」**按钮，程序将从断点处无缝恢复传输。
