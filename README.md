# Cuckoo 私有实时通信平台

供 10 人以下私密使用的轻量级通信工具，完全脱离公网服务器依赖，基于 Radmin VPN 虚拟局域网，采用**星型拓扑（Star Topology）** 架构。

## 架构

```
        ┌──────────┐
        │  房主 Host │  ← 中心服务器，转发/混音/分发
        │  (Server) │
        └─────┬─────┘
      ┌───────┼───────┐
      │       │       │
   ┌──┴──┐ ┌──┴──┐ ┌──┴──┐
   │房客1│ │房客2│ │房客N│  ← 最多 9 位房客
   └─────┘ └─────┘ └─────┘
```

- **房主（Host）**：运行服务端，管理房间、转发文本/文件、混音分发语音、采集分发投屏画面
- **房客（Client）**：连接房主，接收多媒体流，发送自己的语音、文本和文件

## 功能

| 功能 | 说明 | 通道 |
|------|------|------|
| 投屏 | 房主采集屏幕 → JPEG 编码 → 广播给所有房客 | TCP 5000 |
| 语音通话 | 全双工，所有用户 UDP 发至房主 → MCU 混音 → 广播 | UDP 5001 |
| 文件传输 | 支持文件和文件夹传输，文件夹保留目录结构。任意用户发送 → 房主接收或中继转发 → 目标接收 | TCP 5000 |
| 文字聊天 | 任意用户发送 → 房主广播给所有人 | TCP 5000 |

### 协议设计

**TCP 帧格式**：`[4B 总长度][1B 消息类型][4B 发送者ID][4B 目标ID][N字节数据体]`

消息类型：`0x01` 文本 / `0x02` 文件元数据 / `0x03` 文件数据块 / `0x04` 投屏帧 / `0x05` 控制信令

**文件元数据格式**：`[4B base_name_len][base_name][4B name_len][name][8B size][4B target_id]`

- 单文件：`base_name` 为空，`name` 为文件名
- 文件夹：`base_name` 为文件夹名，`name` 为文件相对路径（如 `sub/file.txt`），接收端在 `Downloads/文件夹名/` 下保留完整目录结构

**UDP 语音帧**：`[2B 发送者ID][2B 序列号][N字节 PCM 数据]`

ID 约定：`0` = 房主，`1-9` = 房客，`0xFFFF` = 广播

## 前提条件

1. **操作系统**：Windows 11 x64
2. **Radmin VPN**：所有参与者安装并连接至同一虚拟网络，获得可达的虚拟 IP（如 `10.x.x.x`）
3. **Windows 防火墙**：需放行 `runtime\python.exe` 的 TCP/UDP 入站与出站
4. **音频设备**：麦克风和扬声器/耳机（语音通话需要，建议佩戴耳机减少回声）

## 使用方式

### 启动程序

双击 `run.bat` 或在命令行中执行：

```
.\runtime\python.exe main.py
```

### 角色选择

程序启动后弹出对话框：

- **房主（Host）**：可选输入昵称，点击确认 → 创建房间等待房客加入
- **房客（Guest）**：输入昵称 + 房主的 Radmin VPN IP → 加入房间

### 功能使用

连接成功后，主窗口包含四个 Tab：

| Tab | 操作说明 |
|-----|---------|
| 投屏 | 房主点击「开始投屏」，所有房客自动显示画面 |
| 语音 | 任何人点击「开启麦克风」即可发言，多人同时语音自动混音 |
| 文件 | 选择目标用户 → 选择文件或文件夹 → 发送（房主/房客均可发送，文件夹传输保留目录结构） |
| 文字 | 输入文字发送，所有人可见（显示发送者昵称） |

房客可通过状态栏「检测在线状态」按钮检查房主是否在线。

## 项目结构

```
Cuckoo/
├── core/               # 核心网络层
│   ├── protocol.py     # 统一通信协议（TCP帧/UDP帧/昵称注册表）
│   ├── server.py       # 房主端 Server（Accept/路由/ClientManager）
│   └── client.py       # 房客端 ClientConnection
├── func/               # 功能模块
│   ├── screen_share/   # 投屏（host.py 采集广播 / guest.py 接收渲染）
│   ├── voice_chat/     # 语音（mixer.py MCU混音 / guest_audio.py 收发）
│   └── file_transfer/  # 文件（host_file.py 接收+中继）
├── ui/                 # 界面层
│   ├── main_window.py  # 主窗口（控制层）
│   ├── start_dialog.py # 启动对话框
│   └── tabs/           # 四个功能 Tab 页面
├── common/             # 公共模块
│   ├── logger.py       # 线程安全内存日志
│   └── network.py      # TCP/UDP 基础工具
├── config.py           # 全局配置常量
└── main.py             # 程序入口
```

## 环境维护

如需重新安装依赖：

```
.\runtime\python.exe -m pip install PySide6 opencv-python mss pyaudio numpy
```

> `runtime` 目录为嵌入式 Python 3.11.9 环境，无需在系统中安装 Python。
